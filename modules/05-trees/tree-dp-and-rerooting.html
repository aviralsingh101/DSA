Tree DP & Rerooting

One DFS computes every subtree answer; a second DFS reroots, combining "down" with "the rest of the tree" so every vertex can be treated as the root in O(n).

Hard 26 min read Prerequisites: Binary Tree Problem Patterns, DFS & Components tree DP rerooting P1

Why this exists

Interview diameter is one global. CP asks "for every vertex, the longest path starting there", or "sum of distances to all others", or "whether the tree stays balanced if we root here". Computing n independent DFSes is O(n^2). Tree DP is one down-DFS of subtree summaries, then optionally a reroot-DFS that pushes the parent's "outside" answer into each child in O(1) or O(deg) extra.

The algebraic requirement is that you can merge a child's contribution and an "outside" contribution. Sum of distances: down[u] = sum (down[v]+sz[v]), then reroot ans[v] = ans[u] + n - 2*sz[v]. Longest-out-path needs the top-two child depths because the excluded child might have been the best.

CF 219D choosing capital, CF 161D distance in tree, and "sum of distances" (LC 834) are the cluster. If the merge is not invertible, rerooting needs the top-two trick or a second pass that recomputes from siblings.

Subtree DP answers questions about the rooted tree. Rerooting reuses those summaries so every vertex's "if I were root" answer is O(1) extra after O(n) preprocess.

Recognise this pattern

Say yes when you see

  • For every vertex, some aggregate of the tree rooted there
  • Sum of distances to all nodes (LC 834)
  • Longest path starting at each vertex / height of every rerooting
  • Count of good / black-white / capital-moving reroots (CF 219D)
  • n=1e5 so n independent DFSes are impossible

Not this pattern when

  • One global diameter / one root fixed by the statement → one DFS is enough
  • The graph is not a tree (cycles) → different DP
  • Queries on paths between arbitrary pairs → LCA / HLD / Euler+segtree
  • Offline point updates of values with subtree queries → Euler tour + Fenwick

Core idea and the invariant

Down: dfs(u, p) computes sz[u], down[u] from children only. Example sum of distances: sz[u]=1+sum sz[v], down[u]=sum (down[v]+sz[v]). Then ans[0]=down[0].

Reroot: dfs2(u, p). For each child v, ans[v] = ans[u] - sz[v] + (n - sz[v]) = ans[u] + n - 2*sz[v] for sum-of-distances. Recurse. For max-height, pass the best outside depth, using the top two child depths so the excluded child's outside is the second-best.

After the down pass, down[u] is the answer on the subtree of u. After reroot, ans[u] is the answer on the whole tree as if rooted at u.

ans[v] = combine(ans[u] without v's subtree, down[v])

Algorithm

  1. Build undirected lists, n-1 edges, root at 0.
  2. Down DFS: skip parent; compute sz and down from children.
  3. ans[root] = down[root] (or a custom combine).
  4. Reroot DFS: for each child, write ans[child] from ans[u] and sz[child] (or top-two).
  5. Top-two when the merge is max, not a group with inverse.
  6. long for sums; iterative stack if n=2e5.

Java implementation

JavaNDfs.java
import java.util.*;
    public class NDfs {
        static List<List<Integer>> g;
        static int dfs(int u, int p) {
            int s = 0;
            for (int v : g.get(u)) if (v != p) s += dfs(v, u) + size(v, u);
            return s;
        }
        static int size(int u, int p) {
            int s = 1;
            for (int v : g.get(u)) if (v != p) s += size(v, u);
            return s;
        }
        public static void main(String[] args) {
            g = new ArrayList<>();
            for (int i = 0; i < 5; i++) g.add(new ArrayList<>());
            int[][] e = {{0,1},{1,2},{1,3},{0,4}};
            for (int[] x : e) { g.get(x[0]).add(x[1]); g.get(x[1]).add(x[0]); }
            System.out.println(dfs(0, -1));
        }
        // Input : 5-node sample, sum of distances from 0
        // Output: 6
    }
JavaRerootSum.java
import java.util.ArrayList;
    import java.util.Arrays;
    import java.util.List;
    
    public class RerootSum {
        static List<List<Integer>> g;
        static int n;
        static int[] sz;
        static long[] down, ans;
    
        static void dfs1(int u, int p) {
            sz[u] = 1;
            for (int v : g.get(u)) if (v != p) {
                dfs1(v, u);
                sz[u] += sz[v];
                down[u] += down[v] + sz[v];
            }
        }
        static void dfs2(int u, int p) {
            for (int v : g.get(u)) if (v != p) {
                ans[v] = ans[u] + n - 2L * sz[v];
                dfs2(v, u);
            }
        }
        public static void main(String[] args) {
            n = 5;
            g = new ArrayList<>();
            for (int i = 0; i < n; i++) g.add(new ArrayList<>());
            int[][] e = {{0,1},{1,2},{1,3},{0,4}};
            for (int[] x : e) { g.get(x[0]).add(x[1]); g.get(x[1]).add(x[0]); }
            sz = new int[n]; down = new long[n]; ans = new long[n];
            dfs1(0, -1);
            ans[0] = down[0];
            dfs2(0, -1);
            System.out.println(Arrays.toString(ans));
        }
        // Input : tree 0-1-2, 1-3, 0-4
        // Output: [6, 5, 8, 8, 9]
    }
JavaTopTwoHeight.java
import java.util.*;
    public class TopTwoHeight {
        static List<List<Integer>> g;
        static int[] down;
        static void dfs(int u, int p) {
            down[u] = 0;
            for (int v : g.get(u)) if (v != p) {
                dfs(v, u);
                down[u] = Math.max(down[u], down[v] + 1);
            }
        }
        public static void main(String[] args) {
            g = new ArrayList<>();
            for (int i = 0; i < 5; i++) g.add(new ArrayList<>());
            int[][] e = {{0,1},{1,2},{1,3},{0,4}};
            for (int[] x : e) { g.get(x[0]).add(x[1]); g.get(x[1]).add(x[0]); }
            down = new int[5];
            dfs(0, -1);
            System.out.println(Arrays.toString(down));
        }
        // Input : same tree, down-height from 0
        // Output: [2, 1, 0, 0, 0]
    }

Complexity

Time O(n) Space O(n)

Each edge is traversed a constant number of times across two DFS passes. Combining a child is O(1) for sums, O(deg) total per node for top-two (still O(n) because sum of deg = 2n-2).

T = Θ(n) versus naive Θ(n^2)

If the merge needs a full multiset of child answers, you pay extra (small-to-large, or a heap).

Edge cases and pitfalls

  • Forgetting to skip the parent
    Infinite recursion on an undirected edge stored both ways.
    if (v == p) continue; every loop.
  • int overflow of n*dist
    ans[u] up to n*(n-1) / something times values. int wraps.
    long[] ans, down.
  • Reroot max without top-two
    You subtract the child's depth from a max that was that child; outside becomes 0 wrongly.
    Store best and second-best child depths at u.
  • sz[v] after rerooting used as if still rooted at 0
    The formula ans[u]+n-2*sz[v] needs sz[v] = size of v's down-subtree in the first rooting, which stays valid for the child v of u on the down tree.
    Do not recompute sz during dfs2 unless you know why.
  • Stack overflow
    A path of 2e5. JVM dies.
    Iterative DFS or increase stack; contests often have a chain anti-rec test.

Interview follow-ups

Why n - 2*sz[v]?

Moving the root from u to child v: every node in v's subtree is 1 closer, everyone else is 1 farther. Closer count = sz[v], farther = n-sz[v], delta = (n-sz[v]) - sz[v].

When is rerooting impossible in O(n)?

When you cannot compute "parent's answer without this child" in O(1) or O(deg). Then small-to-large, or accept O(n log n) / O(n^2).

Diameter via rerooting?

Height of a rerooting is the eccentricity of that vertex. Diameter = max eccentricity, also = max over v of down[v]+up[v]. Two BFS is shorter if you only need the diameter value.

Weighted edges?

Same formulas with +w(u,v) instead of +1, and "n-2sz" becomes a weighted analogue: minus 2*sum of subtree weights plus total. Track subtree weight sum.

Recap

  • Down DFS = subtree summaries.
  • Reroot DFS = push the outside answer to each child.
  • Sum of distances: ans[v]=ans[u]+n-2*sz[v].
  • Max needs top-two child contributions.
  • O(n), not O(n^2). long, skip parent.
