Bitmask DP

When n ≤ 20 the subset is the state: dp[mask] (and maybe a last vertex) enumerates 2n subsets in a DAG of popcounts.

Hard 26 min read Prerequisites: DP Foundations, Bit Manipulation bitmask TSP subset P1

Why this exists

n ≤ 20 is not a suggestion of brute force permutations. It is a signature for 2n n or 2n n² DP over subsets. Held-Karp TSP, assignment, "smallest team covering all skills", and "number of Hamiltonian paths" all live here.

The mask is an integer whose bits remember which items / vertices / skills are used. Transitions turn a bit off (or on) and maybe record who was last. Iterating masks in order of popcount (or by the natural 0..2^n-1 increasing order, which adds bits) is the topo order.

P1 because the bit tricks (iterate submasks, lowest set bit, popcount) are as much the topic as the recurrence, and because a missed bit means a silent wrong count.

dp[mask] is the answer for exactly the subset whose bits are set. A transition names one element of the subset as "the one we added last".

Recognise this pattern

Say yes when you see

  • n ≤ 16 .. 22, and the state must remember an arbitrary subset
  • TSP / shortest Hamiltonian path in a dense small graph
  • Assignment: n jobs, n workers, min cost bijection
  • Cover all skills / all remaining with a smallest team
  • Count Hamiltonian paths, or DP over used vertices plus last

Not this pattern when

  • n = 40 subset-sum → meet-in-the-middle, not 2^n n DP on one side only if n=40 full
  • n = 1e5 → the subset cannot be the state
  • SOS over all submasks of all masks is a different (next) page
  • The graph is a DAG of n=1e5 → DAG DP, not a mask

Masks as vertices of a DAG

Assignment dry-run: n = 3 workers, costs[i][j] = cost of worker i doing job j, jobs are bits. dp[mask] = min cost to assign the workers 0..popcount(mask)-1 to the job subset mask (or: workers are bits). We take the second convention: bits = used jobs, and we assign workers in order 0,1,2,... so dp[mask] uses the first popcount(mask) workers.

Held-Karp: dp[mask][u] = min cost of a path that visits exactly the vertices in mask and ends at u. Transition: for v in mask, v != u, dp[mask][u] = min dp[mask^(1<

dp[mask][u] is the best cost (or ways) of visiting exactly the set mask, currently sitting at u (u's bit is on).

dp[mask][u] = min_v dp[mask without u][v] + w[v][u]
Iterate set bits

for (int s = mask; s != 0; s &= s-1) { int v = Integer.numberOfTrailingZeros(s); } visits each set bit of mask in O(popcount). Do not loop v = 0..n-1 if n is 20 and you are inside another n loop unless you must.

Java int sign bit

1<<31 is negative. Keep n ≤ 30 for int masks, or use long and 1L<<i. Iterate with s = (s-1)&mask on ints only when mask is non-negative.

Algorithm

  1. Confirm n ≤ 20 and that the forgotten information is exactly a subset.
  2. Allocate dp[1< or dp[1<
  3. Base: empty mask 0, or singletons 1<
  4. For mask = 0 .. (1< for each set bit u, for each previous v, relax.
  5. Use n & -n / trailing zeros to iterate set bits.
  6. Answer is min over endings, plus the return edge for a cycle.
  7. Reconstruct with a parent pair (prev mask, prev u).

Java implementation

JavaTspRec.java
public class TspRec {
    
        static int rec(int[][] w, int used, int u, int n) {
            if (used == (1 << n) - 1) {
                return w[u][0];
            }
            int best = Integer.MAX_VALUE / 4;
            for (int v = 0; v < n; v++) {
                if ((used & (1 << v)) == 0) {
                    best = Math.min(best, w[u][v] + rec(w, used | (1 << v), v, n));
                }
            }
            return best;
        }
    
        public static void main(String[] args) {
            int[][] w = {{0, 5, 1}, {5, 0, 2}, {1, 2, 0}};
            System.out.println(rec(w, 1, 0, 3));
        }
        // Input : n=3, weights as in the figure, start 0, return to 0
        // Output: 8
    }
JavaTspMemo.java
import java.util.Arrays;
    
    public class TspMemo {
    
        static int rec(int[][] w, int used, int u, int n, int[][] memo) {
            if (used == (1 << n) - 1) {
                return w[u][0];
            }
            if (memo[used][u] != -1) {
                return memo[used][u];
            }
            int best = Integer.MAX_VALUE / 4;
            for (int v = 0; v < n; v++) {
                if ((used & (1 << v)) == 0) {
                    best = Math.min(best, w[u][v] + rec(w, used | (1 << v), v, n, memo));
                }
            }
            return memo[used][u] = best;
        }
    
        public static void main(String[] args) {
            int[][] w = {{0, 5, 1}, {5, 0, 2}, {1, 2, 0}};
            int n = 3;
            int[][] memo = new int[1 << n][n];
            for (int[] row : memo) {
                Arrays.fill(row, -1);
            }
            System.out.println(rec(w, 1, 0, n, memo));
        }
        // Input : same
        // Output: 8
    }
JavaTspTab.java
import java.util.Arrays;
    
    public class TspTab {
    
        static int tsp(int[][] w) {
            int n = w.length;
            int inf = Integer.MAX_VALUE / 4;
            int[][] dp = new int[1 << n][n];
            for (int[] row : dp) {
                Arrays.fill(row, inf);
            }
            dp[1][0] = 0;
            for (int mask = 1; mask < (1 << n); mask++) {
                for (int u = 0; u < n; u++) {
                    if ((mask & (1 << u)) == 0) {
                        continue;
                    }
                    for (int v = 0; v < n; v++) {
                        if ((mask & (1 << v)) != 0) {
                            continue;
                        }
                        int nmask = mask | (1 << v);
                        dp[nmask][v] = Math.min(dp[nmask][v], dp[mask][u] + w[u][v]);
                    }
                }
            }
            int best = inf;
            int full = (1 << n) - 1;
            for (int u = 1; u < n; u++) {
                best = Math.min(best, dp[full][u] + w[u][0]);
            }
            return best;
        }
    
        public static void main(String[] args) {
            int[][] w = {{0, 5, 1}, {5, 0, 2}, {1, 2, 0}};
            System.out.println(tsp(w));
        }
        // Input : same
        // Output: 8
    }

Interview follow-ups

Why is 2^n n^2 better than n!?

n! paths remember the whole order. DP remembers only the set and the last vertex, which is enough for the next edge. That is optimal substructure: the best path through a set ending at u does not care about the order before u, only the cost.

How do I iterate all submasks of a mask?

for (int s = mask; ; s = (s-1) & mask) { ... if (s==0) break; }. Across all masks that is 3^n, which is SOS without the smart order. Prefer the SOS page when you need F[mask] = sum over submasks.

Can I bitmask a grid of 8x8?

If the state is one row's occupancy, n = number of columns ≤ 8 is classic "profile DP" / broken profile. That is bitmask DP on a sliding row, still this family, with extra care for vertical constraints.

TSP approximation?

Held-Karp is exact. For n > 20 you need Christofides / local search / ILP, which are not this course. In contests, n > 20 means the graph is special (metric on a line, bitonic, DAG).

Recap

  • n ≤ 20 ⇒ 2n subset states, never n!.
  • dp[mask][u] = best for this set, currently at u.
  • Increasing mask is a topo order (bits only turn on).
  • inf = MAX/4, start with the start bit on.
  • Iterate set bits with s &= s-1.
