Sum Over Subsets DP

Sum over subsets in O(n 2n) instead of O(3n): for each bit, add the values of masks that differ only in that bit.

Hard 24 min read Prerequisites: Bitmask DP SOS submasks zeta transform P2

Why this exists

Naive F[mask] = sum of A[sub] over sub subseteq mask is 3n if you loop every mask and every submask. SOS (sum over subsets) does the same zeta transform in n 2n by a DP that looks like a fast Walsh/zeta: for bit b from 0 to n-1, for every mask with bit b set, add the value of mask without b.

That one transform is the bottleneck in "for every mask, combine with every submask" problems: subset-OR convolution, counting pairs (i, j) with a[i]|a[j] = x, sum of f[sub] * g[mask^sub], and CF classics like 165E Compatible Numbers.

P2 because the implementation is short and the mistakes (wrong loop order, summing supersets vs subsets, in-place twice) are silent. Draw the n=3 cube once.

After processing bit b, every mask has already absorbed all submasks that differ only in the processed bits. At the end, f[mask] holds the sum over all submasks.

Recognise this pattern

Say yes when you see

  • F[mask] should be the sum / or / min of A over all submasks of mask
  • n ≤ 20 and 3^n TLE but n 2^n fits
  • Compatible pairs: a[i] & a[j] = 0, or a[i] | a[j] = ALL
  • Subset convolution (with extra extra-bits of popcount)
  • For every mask, query the sum of an array over its submasks, many queries

Not this pattern when

  • You only need one mask's submasks → iterate s = (s-1)&mask once, O(2^{popcount})
  • n = 40 → not 2^n memory
  • Ordinary knapsack / TSP → previous pages
  • You need sum over supersets: run SOS on the complement, or reverse the add direction

You read mask without bit b, which is a smaller integer, so 0..2^n-1 is safe in-place. If you reversed the add (supersets), you may need to walk masks downwards. Draw n=2 once if unsure.

OR-convolution via SOS

To compute C[k] = sum_{i|j=k} A[i]B[j], zeta-transform A and B, pointwise multiply, inverse zeta. That is the subset/OR convolution. XOR uses FWHT instead.

Algorithm

  1. Copy A into f of length 1<<n.
  2. For b = 0 .. n-1:
  3. For mask = 0 .. (1<<n)-1: if bit b is set, f[mask] += f[mask ^ (1<<b)].
  4. Use long if the sum of A can exceed 2e9.
  5. Now f[mask] is the submask sum. Inverse: the same loops with -=.
  6. Supersets: add the other way, or reverse the array indices by ~mask.
  7. Do not run the transform twice unless you meant to.

Java implementation

JavaSosNaive.java
import java.util.Arrays;
    
    public class SosNaive {
    
        static long[] sos(long[] a, int n) {
            int N = 1 << n;
            long[] f = new long[N];
            for (int mask = 0; mask < N; mask++) {
                for (int s = mask; ; s = (s - 1) & mask) {
                    f[mask] += a[s];
                    if (s == 0) {
                        break;
                    }
                }
            }
            return f;
        }
    
        public static void main(String[] args) {
            System.out.println(Arrays.toString(sos(new long[] {1, 2, 3, 4, 5, 6, 7, 8}, 3)));
        }
        // Input : A=1..8, n=3
        // Output: [1, 3, 4, 10, 6, 14, 16, 36]
    }
JavaSosDp.java
import java.util.Arrays;
    
    public class SosDp {
    
        static long[] sos(long[] a, int n) {
            int N = 1 << n;
            long[] f = Arrays.copyOf(a, N);
            for (int b = 0; b < n; b++) {
                for (int mask = 0; mask < N; mask++) {
                    if ((mask & (1 << b)) != 0) {
                        f[mask] += f[mask ^ (1 << b)];
                    }
                }
            }
            return f;
        }
    
        public static void main(String[] args) {
            System.out.println(Arrays.toString(sos(new long[] {1, 2, 3, 4, 5, 6, 7, 8}, 3)));
        }
        // Input : A=1..8, n=3
        // Output: [1, 3, 4, 10, 6, 14, 16, 36]
    }
JavaSosMobius.java
import java.util.Arrays;
    
    public class SosMobius {
    
        static long[] mobius(long[] f, int n) {
            int N = 1 << n;
            long[] a = Arrays.copyOf(f, N);
            for (int b = 0; b < n; b++) {
                for (int mask = 0; mask < N; mask++) {
                    if ((mask & (1 << b)) != 0) {
                        a[mask] -= a[mask ^ (1 << b)];
                    }
                }
            }
            return a;
        }
    
        public static void main(String[] args) {
            long[] f = {1, 3, 4, 10, 6, 14, 16, 36};
            System.out.println(Arrays.toString(mobius(f, 3)));
        }
        // Input : SOS result of 1..8
        // Output: [1, 2, 3, 4, 5, 6, 7, 8]
    }

Edge cases and pitfalls

    You wanted "how many a[i] are supersets of mask" and ran the standard SOS.

  • In-place SOS twice
    Second pass turns sums-of-sums into garbage.

  • XOR convolution with SOS

Interview follow-ups

Why n 2^n and not 3^n?

Each element A[sub] should be added to every mask supseteq sub. There are n bits to "turn on" from sub to mask. SOS adds it along those bits one at a time, so each (sub, extra-bit) pair is handled once, totalling n 2^n, not one add per (sub, mask).

How is this related to FMT / zeta?

It is the fast zeta transform on the subset poset. Möbius inversion is the inverse transform. The same idea on other posets gives AND/OR/XOR convolutions.

Can I SOS with min instead of +?

Yes if you want f[mask] = min of A on submasks: f[mask] = min(f[mask], f[mask without b]). Idempotent semirings work; subtraction inverse does not. For min, there is no Möbius.

Query-only, n=20, q=1e5?

Build SOS once in n 2^n, then each query is O(1) if it is a submask-sum of a stored mask. If queries are arbitrary, that is a different structure.

Hint for CF 165E Compatible Numbers

Two numbers are compatible if a & b = 0, i.e. b is a submask of ~a (restricted to n bits). SOS an existence array of the input values over supersets (or submasks of the complement). For each a print any stored value whose bits sit inside ~a, or -1.

Hint for CF 449D

Count subsets whose AND is 0. Inclusion via SOS: let g[mask] = count of values that are supersets of mask. Then 2^{g[mask]} subsets have AND supseteq mask. Möbius to get AND == 0. Mod 1e9+7, handle 2^n with fastpow.

Recap

  • F[mask] = sum of A over submasks in O(n 2^n), not O(3^n).
  • For each bit, add f[mask without bit] into f[mask].
  • Inverse is the same loop with minus.
  • Supersets flip the direction or reverse the index.
  • OR-convolution = zeta, multiply, inverse zeta.
