Bellman-Ford & Negative Cycles

Relax every edge n-1 times. A successful relaxation on the n-th pass is a negative cycle that can reach the target.

Medium 22 min read Prerequisites: Dijkstra's Algorithm Bellman-Ford negative cycle shortest path P1

Why this exists

Dijkstra assumes non-negative weights. One negative edge and the extracted-min order is a lie. Bellman-Ford only assumes there is no negative cycle on the path you care about, and it detects the ones that exist.

The algorithm is the definition of a shortest path of at most k edges: after i full relax passes, dist[v] is the cheapest walk from the source that uses at most i edges. A simple path has at most n-1 edges, so n-1 passes suffice. A cheap n-th relaxation means a cycle with negative total weight.

Interview and contest uses: "cheapest flights with at most k stops" is Bellman-Ford stopped early; "can I make money forever on these exchange rates" is a negative cycle on -log(rate).

After i relax-all-edges passes, dist is exact for paths of at most i edges. One more success on pass n is a negative cycle, not a longer simple path.

Recognise this pattern

Say yes when you see

  • Directed (or undirected) graph with negative weights, single source
  • Detect whether a negative cycle exists, or can reach a given node
  • "At most k edges / k stops" — stop after k relax passes
  • Arbitrage / exchange rates (negate the log of the rate)
  • n is a few thousand, m a few thousand — O(nm) fits

Not this pattern when

  • Non-negative weights and you need speed → Dijkstra
  • All-pairs on a dense graph of n <= 400 → Floyd-Warshall
  • 0-1 weights → 0-1 BFS
  • You only need a spanning tree → MST, not shortest paths

Constraint tell: n ≤ 2×10³, m ≤ 5×10³ is the O(nm) window. Distances need long: n * |w| can hit 1e14. Undirected negative edges are already a negative cycle of length 2.

Core idea and the invariant

Store an edge list. dist[src] = 0, rest INF. Repeat n-1 times: for every edge u o v of weight w, if dist[u] is finite and dist[u]+w < dist[v], write the new distance and par[v] = u.

Nth pass: any successful relax is a node on (or reachable from) a negative cycle. To recover the cycle, walk parent pointers n times from that node to enter the cycle, then walk once more to print it. To mark every node that can be driven to -INF, BFS/DFS from all nth-pass victims along the graph (or the reverse graph, depending on the question).

After pass i, dist[v] equals the minimum weight of a walk from the source to v that uses at most i edges, or INF if none exists. A simple path cannot need more than n-1 edges, so pass n-1 is exact in a graph with no negative cycle on that path.

Structure

Algorithm

  1. dist[src] = 0, others INF, parent = -1.
  2. Repeat n-1 times: for every edge, relax dist[v] = min(dist[v], dist[u]+w) when dist[u] is finite.
  3. Optional early exit if a pass changes nothing.
  4. Nth pass: collect every vertex whose distance still drops.
  5. Cycle recover: from any victim walk parent n times, then walk until repeat.
  6. -INF reach: flood from those victims (forward or reverse, as the question asks).

Java implementation

JavaBellmanFordBrute.java
import java.util.Arrays;
    public class BellmanFordBrute {
        static long[] bf(int n, int[][] edges, int src) {
            long[] d = new long[n];
            Arrays.fill(d, Long.MAX_VALUE / 4);
            d[src] = 0;
            for (int i = 0; i < n - 1; i++)
                for (int[] e : edges)
                    if (d[e[0]] + e[2] < d[e[1]]) d[e[1]] = d[e[0]] + e[2];
            return d;
        }
        public static void main(String[] args) {
            int[][] e = {{0,1,5},{0,2,4},{2,1,-2},{1,3,1},{2,3,3}};
            System.out.println(Arrays.toString(bf(4, e, 0)));
        }
        // Input : 4 nodes, edges as above, src 0
        // Output: [0, 2, 4, 3]
    }
JavaBellmanFord.java
import java.util.*;
    public class BellmanFord {
        static boolean hasNegCycle(int n, int[][] edges, int src) {
            long[] d = new long[n];
            Arrays.fill(d, Long.MAX_VALUE / 4);
            d[src] = 0;
            for (int i = 0; i < n - 1; i++)
                for (int[] e : edges)
                    if (d[e[0]] + (long) e[2] < d[e[1]]) d[e[1]] = d[e[0]] + e[2];
            for (int[] e : edges)
                if (d[e[0]] + (long) e[2] < d[e[1]]) return true;
            return false;
        }
        public static void main(String[] args) {
            int[][] e = {{0,1,5},{0,2,4},{2,1,-2},{1,3,1},{2,3,3}};
            System.out.println(hasNegCycle(4, e, 0));
            int[][] cyc = {{0,1,1},{1,2,-3},{2,0,1},{0,3,4}};
            System.out.println(hasNegCycle(4, cyc, 0));
        }
        // Input : first graph no cycle; second 0-1-2-0 weight -1
        // Output: false
        //         true
    }
JavaKStops.java
import java.util.Arrays;
    public class KStops {
        static int cheapest(int n, int[][] flights, int src, int dst, int k) {
            long[] d = new long[n];
            Arrays.fill(d, Long.MAX_VALUE / 4);
            d[src] = 0;
            for (int i = 0; i <= k; i++) {
                long[] nd = d.clone();
                for (int[] e : flights)
                    if (d[e[0]] + e[2] < nd[e[1]]) nd[e[1]] = d[e[0]] + e[2];
                d = nd;
            }
            return d[dst] >= Long.MAX_VALUE / 8 ? -1 : (int) d[dst];
        }
        public static void main(String[] args) {
            int[][] f = {{0,1,100},{1,2,100},{0,2,500}};
            System.out.println(cheapest(3, f, 0, 2, 1));
        }
        // Input : flights 0-1 100, 1-2 100, 0-2 500; k=1
        // Output: 200
    }

Complexity

Time O(n m) Space O(n + m)

n-1 passes, each scans m edges, so O(nm). SPFA is faster on random graphs and worst-case exponential — do not use it when an adversary exists unless you have a queue-count cutoff that falls back to BF.

Edge cases and pitfalls

  • Relaxing from INF
    INF + negative becomes a finite junk distance and "reaches" a node that the source cannot.
    Only relax when dist[u] is finite.
  • int overflow
    n * |w| exceeds Integer.MAX_VALUE and a real shortest path looks like a negative cycle.
    long[] dist. Sentinel Long.MAX_VALUE/4 so additions do not overflow.
  • Nth-pass victim is not on the cycle
    It is only reachable from the cycle. Walking parents once may stop at a tree edge.
    Walk parent n times first to land on the cycle, then walk until you repeat.
  • Undirected negative edge
    Storing both directions of a negative edge is a 2-cycle of negative weight.
    Undirected negatives are almost always a modelling error. Confirm the statement.
  • In-place relax for "at most k edges"
    Using one array lets a pass use a distance written earlier in the same pass, which is a path of more than one extra edge.
    Clone dist each pass (LC 787).

Interview follow-ups

Why n-1, not n?

A simple path has at most n-1 edges. If a cheaper walk uses n edges it repeats a vertex, hence contains a cycle, hence (if it is cheaper) a negative cycle.

Does BF work on undirected graphs?

Yes if every weight is non-negative. A single negative undirected edge is a negative cycle. Model the graph as directed with both orientations only when weights are ≥ 0.

How do you list every node that can be driven to -INF?

After the nth pass, the victims are nodes that improved. DFS/BFS forward from them (and, if the question is "source can cheat to reach t", also require they are reachable from the source).

Bellman-Ford vs Dijkstra with potentials?

Johnson's algorithm runs BF once from a dummy source to compute potentials, then Dijkstra with non-negative reduced costs for every source. That is the all-pairs algorithm when n is too big for Floyd and weights can be negative but there is no negative cycle.

Recap

  • Relax all edges n-1 times; dist is then exact for simple paths.
  • A success on pass n is a negative cycle.
  • Do not relax from INF.
  • k-stop problems use a cloned array per pass.
  • Walk parent n times before printing the cycle.
