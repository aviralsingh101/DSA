Max Flow / Min Cut

Max flow equals min cut. Edmonds-Karp BFS-augments in O(V E²); Dinic layers + blocking flow is the contest default.

Hard 26 min read Prerequisites: BFS max flow min cut Dinic P2

Why this exists

A flow is an assignment of values to directed edges that respects capacity and conservation. The maximum amount you can push from s to t equals the capacity of the cheapest s-t cut — the max-flow min-cut theorem. That one sentence turns "separate these vertices" and "assign jobs under capacities" into a flow network.

Ford-Fulkerson finds an s-t path in the residual graph and pushes the bottleneck. Edmonds-Karp always takes a shortest residual path (BFS) and is polynomial. Dinic builds a level graph and then a blocking flow; on unit networks it is extremely fast and is what you write in a contest.

Modelling is the skill: bipartite matching is unit-capacity flow; project selection is a min-cut; circulation with demands is a max-flow with a super-source. The algorithm is twenty lines; the reduction is the interview.

An augmenting path in the residual graph is a place you can still push. When none exists, the set of nodes reachable from s in the residual graph is a min cut: every forward edge leaving it is saturated.

Recognise this pattern

Say yes when you see

  • Maximum throughput from s to t under capacities
  • Minimum capacity of an edge set whose removal disconnects s from t
  • Bipartite matching via unit flow (next page is the specialised view)
  • Project selection / closure — profit nodes to t, cost nodes from s
  • n a few hundred, m a few thousand — Dinic fits easily

Not this pattern when

  • Uncapacitated connectivity → DFS / bridges
  • Shortest path → Dijkstra; flow does not care about path length except inside Dinic levels
  • Min-cost flow when every unit has a price → MCMF, not this page
  • Undirected unweighted "min edges to disconnect" with unit capacities is flow, but also edge-connectivity via other theorems

Core idea and the invariant

Residual graph: for each original edge u o v of cap c with flow f, residual c-f forward and f backward. An augmenting path is an s-t path of residual > 0. Push the min residual, increase forward flow, decrease backward (undo).

Dinic: BFS to assign levels from s in the residual graph. DFS from s that only walks s o t along edges with level[v]==level[u]+1, using a current-edge pointer, until the level graph is blocked. Repeat.

Conservation: for every v ≠ s,t, inflow = outflow. Capacity: 0 ≤ f(e) ≤ c(e). When no residual s-t path exists, the reachable-from-s set S is a min cut and v(f) = cap(δ(S)).

Algorithm

  1. Build residual: each edge gets a reverse twin of cap 0. Store index of the twin.
  2. Edmonds-Karp: BFS a residual path, push bottleneck, update both directions.
  3. Dinic: BFS levels; DFS blocking flow with a current-edge pointer; repeat while t is reachable.
  4. Stop when BFS cannot reach t. Flow value is the sum leaving s.
  5. Min cut: all vertices reachable from s in the final residual graph; edges S o V\S with original cap > 0.
  6. long for capacities and the answer.

Java implementation

JavaFordFulkerson.java
import java.util.*;
    public class FordFulkerson {
        static int bfs(int[][] cap, int s, int t, int[] par) {
            Arrays.fill(par, -1);
            par[s] = s;
            ArrayDeque<int[]> q = new ArrayDeque<>();
            q.add(new int[] {s, Integer.MAX_VALUE});
            while (!q.isEmpty()) {
                int[] cur = q.poll();
                int u = cur[0], f = cur[1];
                for (int v = 0; v < cap.length; v++) if (par[v] == -1 && cap[u][v] > 0) {
                    par[v] = u;
                    int nf = Math.min(f, cap[u][v]);
                    if (v == t) return nf;
                    q.add(new int[] {v, nf});
                }
            }
            return 0;
        }
        static int maxFlow(int[][] cap, int s, int t) {
            int[] par = new int[cap.length];
            int flow = 0, add;
            while ((add = bfs(cap, s, t, par)) > 0) {
                flow += add;
                for (int v = t; v != s; v = par[v]) { cap[par[v]][v] -= add; cap[v][par[v]] += add; }
            }
            return flow;
        }
        public static void main(String[] args) {
            int[][] c = new int[3][3];
            c[0][1] = 3; c[1][2] = 2; c[0][2] = 1;
            System.out.println(maxFlow(c, 0, 2));
        }
        // Input : s=0,a=1,t=2 caps 3,2,1
        // Output: 3
    }
JavaDinic.java
import java.util.*;
    public class Dinic {
        static class Edge { int to, rev; long cap; Edge(int to, int rev, long cap) { this.to = to; this.rev = rev; this.cap = cap; } }
        List<Edge>[] g;
        int[] lev, it;
        Dinic(int n) {
            g = new List[n];
            for (int i = 0; i < n; i++) g[i] = new ArrayList<>();
        }
        void add(int u, int v, long c) {
            g[u].add(new Edge(v, g[v].size(), c));
            g[v].add(new Edge(u, g[u].size() - 1, 0));
        }
        boolean bfs(int s, int t) {
            lev = new int[g.length];
            Arrays.fill(lev, -1);
            lev[s] = 0;
            ArrayDeque<Integer> q = new ArrayDeque<>();
            q.add(s);
            while (!q.isEmpty()) {
                int u = q.poll();
                for (Edge e : g[u]) if (e.cap > 0 && lev[e.to] < 0) { lev[e.to] = lev[u] + 1; q.add(e.to); }
            }
            return lev[t] >= 0;
        }
        long dfs(int u, int t, long f) {
            if (u == t) return f;
            for (; it[u] < g[u].size(); it[u]++) {
                Edge e = g[u].get(it[u]);
                if (e.cap <= 0 || lev[e.to] != lev[u] + 1) continue;
                long pushed = dfs(e.to, t, Math.min(f, e.cap));
                if (pushed > 0) { e.cap -= pushed; g[e.to].get(e.rev).cap += pushed; return pushed; }
            }
            return 0;
        }
        long maxFlow(int s, int t) {
            long flow = 0;
            while (bfs(s, t)) {
                it = new int[g.length];
                long add;
                while ((add = dfs(s, t, Long.MAX_VALUE / 4)) > 0) flow += add;
            }
            return flow;
        }
        public static void main(String[] args) {
            Dinic d = new Dinic(3);
            d.add(0, 1, 3); d.add(1, 2, 2); d.add(0, 2, 1);
            System.out.println(d.maxFlow(0, 2));
        }
        // Input : same network
        // Output: 3
    }
JavaMinCut.java
import java.util.*;
    public class MinCut {
        static List<Integer> sideS(List<int[]>[] residual, int s) {
            boolean[] vis = new boolean[residual.length];
            ArrayDeque<Integer> q = new ArrayDeque<>();
            q.add(s); vis[s] = true;
            while (!q.isEmpty()) {
                int u = q.poll();
                for (int[] e : residual[u]) if (e[1] > 0 && !vis[e[0]]) { vis[e[0]] = true; q.add(e[0]); }
            }
            List<Integer> S = new ArrayList<>();
            for (int i = 0; i < vis.length; i++) if (vis[i]) S.add(i);
            return S;
        }
        public static void main(String[] args) {
            List<int[]>[] r = new List[3];
            for (int i = 0; i < 3; i++) r[i] = new ArrayList<>();
            r[0].add(new int[] {1, 1});
            System.out.println(sideS(r, 0));
        }
        // Input : residual after a toy run, s can reach 0 and 1
        // Output: [0, 1]
    }

Complexity

Time EK O(V E^2), Dinic O(V^2 E) typical Space O(V + E)

Edmonds-Karp: each augmentation increases the shortest residual distance of some vertex, bounding the number of phases by VE, each a BFS. Dinic: O(V) phases, each a blocking flow; unit networks are much faster in practice (O(E min(E^{1/2}, V^{2/3}))).

Edge cases and pitfalls

  • No reverse edges
    You cannot undo a bad push and the algorithm gets stuck below max flow.
    Every add(u,v,c) creates add(v,u,0) and the two store each other's indices.
  • int overflow on cap sums
    n * 1e9 exceeds int.
    long capacities and flow.
  • Using original caps to read the min cut
    You need residual reachability, not "edges that still have cap".
    BFS from s in the residual after the flow run; cut is S o V\S.
  • Multiple edges overwritten in a matrix
    An adj-matrix residual silently keeps one cap.
    Edge list (Dinic) or add onto the matrix cell.
  • Bidirected input as two independent caps
    Sometimes the statement is undirected: one capacity shared both ways. Model as two directed edges of that cap, which is correct for undirected flow.
    Undirected edge of cap c → add(u,v,c) and add(v,u,c).

Interview follow-ups

State the max-flow min-cut theorem.

In any flow network the value of a maximum s-t flow equals the capacity of a minimum s-t cut. Proof: weak inequality is easy (any flow is ≤ any cut); when FF stops, residual-unreachable t gives a cut of capacity equal to the flow.

How do you recover the cut edges?

S = residual-reachable from s. Cut edges are original edges u o v with u in S, v not in S. Their residual is 0 (they are saturated).

Why Dinic's current-edge pointer?

Once a residual edge is exhausted inside a blocking-flow phase it will not come back in that phase. The pointer makes each phase scan every edge a constant number of times.

Unit-capacity bipartite matching complexity?

Dinic on that network is O(E √V) (Hopcroft-Karp is the same bound with different language). Kuhn is O(VE) and often faster to write for n = 500.

Recap

  • Max flow = min cut. Residual paths are leftover capacity.
  • Every edge needs a reverse twin for undo.
  • Edmonds-Karp = BFS augment. Dinic = levels + blocking flow.
  • Min cut = residual-reachable from s after the run.
  • Modelling (gadgets) is most of the problem.
