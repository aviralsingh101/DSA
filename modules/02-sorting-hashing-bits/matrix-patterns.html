Matrix Patterns

A matrix is an array with 2D indexing: layers for rotate and spiral, in-place markers for set-zeroes, and a staircase walk when rows and columns are sorted.

Medium 22 min read Prerequisites: Two Pointers, Binary Search Basics matrix spiral rotate search 2D P0

Why this exists

Most matrix questions are not graph search. Rotate 90° is transpose then reverse each row. Spiral is four shrinking bounds. Set zeroes is "mark first row/column as a bitset". Search in a row-and-column-sorted matrix is a staircase from the top-right. Once you own those four templates, the rest are payloads.

Index arithmetic is where people bleed time. Off-by-one on layers, walking off the right edge of a spiral, and using the first row as a marker then zeroing it too early are the classic bugs. Drawing the layer and naming top, bottom, left, right removes them.

When the matrix really is a graph (islands, unique paths with obstacles, word search), switch modules: BFS/DFS on the four neighbours. This page is the geometry of a dense grid you scan in a prescribed order, not the implicit graph.

Name the bounds of the current layer (or the current staircase cell). Every index you write should be a function of those bounds, never a hard-coded n-1 inside a nested loop that also shrinks.

Constraint tell: n, m le 400 is in-place geometry; n = 10⁵ as a flattened 1D search still works if you never materialise n². Rotate and set-zeroes must be O(1) extra when they say in-place: the first row/column are the allowed markers.

Core idea and the invariant

Rotate 90° clockwise: a[i][j] → a[j][n-1-i]. In-place: transpose (a[i][j] ↔ a[j][i] for j>i) then reverse each row. Layers work too: cycle four cells. Spiral: while top≤bottom and left≤right, walk right, down, left, up, and shrink the bound you just finished. After walking a side, check the bounds again so a single middle row is not walked twice.

Set zeroes: first pass records which rows/cols contain a zero, using row 0 and col 0 as the bitsets plus one extra boolean for cell [0][0]'s double duty. Second pass zeroes from the inside out so the markers survive. Staircase search: start at top-right; if the cell is too big, move left; too small, move down. Each step discards a row or a column, so O(n+m).

A layer with bounds top, bottom, left, right is processed exactly once, and the next layer is strictly inside:

top++, bottom--, left++, right--

Interview sentence: "I walk the current rectangle's perimeter, then I shrink all four bounds."

Algorithm

  1. Classify: in-place geometry vs search vs grid graph.
  2. Rotate: transpose, reverse rows (clockwise). Undo = reverse then transpose.
  3. Spiral: maintain top, bottom, left, right; shrink after each side; re-check bounds before the reverse walk.
  4. Set zero: marker pass, then zero inner cells, then the first row/col.
  5. LC 74: treat as 1D of length n*m, mid = lo+(hi-lo)/2, map to [mid/m][mid%m].
  6. LC 240: start at [0][m-1], smaller → down, larger → left.
  7. Border flood: DFS/BFS from every border cell of the start state, mark safe, then flip the interior.
  8. Never allocate n² extra if they said in-place.

Java implementation

Allocate a second matrix. Correct, O(n²) extra, the in-place version drops the copy.

JavaRotateBrute.java
import java.util.Arrays;
    
    public class RotateBrute {
        static int[][] rotate(int[][] a) {
            int n = a.length;
            int[][] b = new int[n][n];
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    b[j][n - 1 - i] = a[i][j];
                }
            }
            return b;
        }
    
        public static void main(String[] args) {
            int[][] a = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
            System.out.println(Arrays.deepToString(rotate(a)));
        }
        // Input : [[1,2,3],[4,5,6],[7,8,9]]
        // Output: [[7,4,1],[8,5,2],[9,6,3]]
    }

Rotate in place, spiral order, and staircase search.

JavaMatrixOps.java
import java.util.ArrayList;
    import java.util.Arrays;
    import java.util.List;
    
    public class MatrixOps {
        static void rotate(int[][] a) {
            int n = a.length;
            for (int i = 0; i < n; i++) {
                for (int j = i + 1; j < n; j++) {
                    int t = a[i][j];
                    a[i][j] = a[j][i];
                    a[j][i] = t;
                }
            }
            for (int i = 0; i < n; i++) {
                int l = 0, r = n - 1;
                while (l < r) {
                    int t = a[i][l];
                    a[i][l] = a[i][r];
                    a[i][r] = t;
                    l++;
                    r--;
                }
            }
        }
    
        static List<Integer> spiral(int[][] a) {
            int top = 0, bottom = a.length - 1;
            int left = 0, right = a[0].length - 1;
            List<Integer> out = new ArrayList<>();
            while (top <= bottom && left <= right) {
                for (int j = left; j <= right; j++) {
                    out.add(a[top][j]);
                }
                top++;
                for (int i = top; i <= bottom; i++) {
                    out.add(a[i][right]);
                }
                right--;
                if (top <= bottom) {
                    for (int j = right; j >= left; j--) {
                        out.add(a[bottom][j]);
                    }
                    bottom--;
                }
                if (left <= right) {
                    for (int i = bottom; i >= top; i--) {
                        out.add(a[i][left]);
                    }
                    left++;
                }
            }
            return out;
        }
    
        static boolean searchSorted(int[][] a, int t) {
            int i = 0, j = a[0].length - 1;
            while (i < a.length && j >= 0) {
                if (a[i][j] == t) {
                    return true;
                }
                if (a[i][j] > t) {
                    j--;
                } else {
                    i++;
                }
            }
            return false;
        }
    
        public static void main(String[] args) {
            int[][] a = {{1, 2, 3}, {4, 5, 6}, {7, 8, 9}};
            System.out.println(spiral(a));
            rotate(a);
            System.out.println(Arrays.deepToString(a));
            System.out.println(searchSorted(new int[][] {{1, 4, 7}, {2, 5, 8}, {3, 6, 9}}, 6));
        }
        // Input : spiral then rotate [[1,2,3],[4,5,6],[7,8,9]]; search 6
        // Output: [1, 2, 3, 6, 9, 8, 7, 4, 5]
        //         [[7, 4, 1], [8, 5, 2], [9, 6, 3]]
        //         true
    }

First row and first column as markers. Extra boolean for a[0][0].

JavaSetZeroes.java
import java.util.Arrays;
    
    public class SetZeroes {
        static void setZeroes(int[][] a) {
            int n = a.length, m = a[0].length;
            boolean firstCol = false;
            for (int i = 0; i < n; i++) {
                if (a[i][0] == 0) {
                    firstCol = true;
                }
                for (int j = 1; j < m; j++) {
                    if (a[i][j] == 0) {
                        a[i][0] = 0;
                        a[0][j] = 0;
                    }
                }
            }
            for (int i = 1; i < n; i++) {
                for (int j = 1; j < m; j++) {
                    if (a[i][0] == 0 || a[0][j] == 0) {
                        a[i][j] = 0;
                    }
                }
            }
            if (a[0][0] == 0) {
                Arrays.fill(a[0], 0);
            }
            if (firstCol) {
                for (int i = 0; i < n; i++) {
                    a[i][0] = 0;
                }
            }
        }
    
        public static void main(String[] args) {
            int[][] a = {{1, 1, 1}, {1, 0, 1}, {1, 1, 1}};
            setZeroes(a);
            System.out.println(Arrays.deepToString(a));
        }
        // Input : [[1,1,1],[1,0,1],[1,1,1]]
        // Output: [[1, 0, 1], [0, 0, 0], [1, 0, 1]]
    }

Complexity

Time O(n m) to touch every cell; staircase search O(n + m) Space O(1) extra for in-place rotate / set-zero; O(n m) for spiral output

Rotate, spiral, and set-zeroes each visit every cell a constant number of times: T = Θ(n m). Extra memory is the output list or O(1) markers.

Staircase discards a row or a column per step, at most n+m steps. LC 74 binary search is O(log(n m)) comparisons on a virtual 1D array.

Edge cases and pitfalls

  • Spiral walking a row twice
    After shrinking top, the left-going pass re-reads the same single remaining row.
    if (top <= bottom) before walking left; if (left <= right) before walking up.
  • Zeroing markers too early
    Clearing row 0 in the first inner pass wipes the column-marker bits.
    Zero the inner (n-1)×(m-1) first; then row 0; then col 0.
  • mid * m overflow when flattening LC 74
    int mid = (lo+hi)/2; a[mid/m][mid%m] is fine; (lo+hi)/2 is not the overflow you fear, but lo+hi is.
    int mid = lo + (hi - lo) / 2; always.
  • Staircase starting at bottom-right
    Both directions increase, so you cannot discard a row or a column.
    Start at top-right or bottom-left, where one step is decrease and one is increase.
  • Transpose of a non-square
    In-place swap a[i][j]↔a[j][i] is only for square. Rectangular transpose needs a new array.
    Allocate m×n, or treat rotate as square-only (LC 48 is square).

Variants

VariantWhat changesCode deltaExample
Rotate 180 / 90 counter-clockwise 180 = reverse rows then reverse each row; CCW = transpose then reverse columns. Same four-cycle with the opposite permutation. Useful follow-up to LC 48.
Generate spiral (LC 59) Write 1..n² with the same four bounds into an empty matrix. int k=1; a[top][j]=k++; … LC 59.
Diagonal traverse Group by i+j; even diagonals reversed. Or simulate direction with a bounce. Map<Integer,List> by i+j, then concatenate. LC 498.

Interview follow-ups

Rotate anti-clockwise in place?

Transpose, then reverse each column (or reverse rows first, then transpose). Derive the mapping a[i][j] → a[n-1-j][i] and check one cell.

Can staircase search be binary search?

You can binary-search each row in O(n log m). That is worse than O(n+m) when napprox m, and better when one dimension is tiny. LC 240 wants the staircase.

Set zeroes without using the first row as a marker?

Two boolean arrays of size n and m are O(n+m) extra and simpler. The O(1) version is only required when they insist. Mention both.

Spiral on a jagged / empty matrix?

Guard m=0. A 1×n row is only the rightward pass; the reverse passes must be skipped via the bound checks.

Recap

  • Rotate = transpose + reverse rows.
  • Spiral = four bounds; re-check before reverse sides.
  • Set zero = first row/col as markers, inner first.
  • LC 74 is 1D binary search; LC 240 is a staircase.
  • Islands / surrounded flood from the border, then flip the rest.
