Bit Manipulation

Bits are a 32- or 64-slot boolean array that hardware already ANDs, ORs and XORs in one cycle — subset enumeration, parity, and "every bit independently" all live here.

Medium 22 min read Prerequisites: Complexity Analysis, Java for DSA bits XOR bitmask popcount P0

Why this exists

XOR is addition without carry: x^x = 0, x^0 = x, and XOR is commutative. That is why "every element appears twice except one" is a single accumulator, and why you can swap two ints without a temp. AND/OR are the set operations on the bit-set of a 32-bit mask. Interviews hammer a small toolkit until it is muscle memory.

The other half is subset enumeration. n ≤ 20 means 2^n masks fit in time; each mask is a subset, and mask & (1<<i) tests membership. SOS DP, meet-in-the-middle, and many contest tricks start from that loop. You do not need a bitset class; an int is enough for n≤30, a long for n≤60.

Java-specific traps: >> sign-extends, >>> is logical; Integer.bitCount is popcount; n & -n is the lowest set bit (two's complement). Shifting by 32 on an int is masked to 5 bits, so 1 << 32 is 1, not 0. These are not trivia; they are WA.

Treat the integer as a set of bit positions. XOR toggles, AND intersects, OR unions, and mask ^ (1<<i) flips membership. Most bit problems are set problems in costume.

Recognise this pattern

Say yes when you see

  • "Every number appears twice except one" / "appears three times except one"
  • "Count set bits", "power of two", "range AND / OR"
  • n ≤ 20 and "every subset" — iterate masks 0..(1<<n)-1
  • "Maximum XOR of two numbers", "XOR of a subarray" (prefix XOR)
  • Need to pack several flags into one int (visited subsets, Game of Life states)

Not this pattern when

  • Arbitrary-precision bitsets of size n=1e5 → BitSet or a long[], plus a Fenwick/seg-tree if you need prefixes
  • Maximum XOR of a subarray with n=1e5 → a binary XOR trie, not a nested mask loop
  • Subset sums with n=40 → meet in the middle, not 2^40
  • Just need popcount of one number once → Integer.bitCount, stop

Core idea and the invariant

XOR fold: the unique element in a twice-array is the XOR of everything. For three times, count each bit mod 3 (or the two-bit state machine). Power of two: exactly one bit set, (x & (x-1)) == 0 and x > 0. Turn off lowest bit: x &= x-1, which is also the kernel of Kernighan popcount.

Masks: bit i is on iff element i is in the subset. Iterate submasks of m with s = (s-1) & m. Prefix XOR makes subarray XOR a two-endpoint query, same identity as prefix sums. Java: prefer Integer.bitCount, Integer.numberOfTrailingZeros, Integer.highestOneBit over hand-rolled loops unless you are teaching them.

XOR is its own inverse and is associative:

x ⊕ x = 0,  x ⊕ 0 = x,  (a⊕b⊕c) ⊕ b = a⊕c

Interview sentence: "Pairs cancel under XOR; a mask is a subset of bit positions."

Which bit tool?

Algorithm

  1. XOR fold when pairs (or even counts) should vanish.
  2. x & (x-1) drops the lowest set bit; loop for popcount.
  3. x & -x isolates the lowest set bit (Fenwick step).
  4. Enumerate masks for (int m = 0; m < (1 << n); m++) when n ≤ 20. Use 1L << i for i up to 62.
  5. Submasks: for (int s = m; s > 0; s = (s - 1) & m).
  6. Prefix XOR for subarray XOR queries: px[r+1]^px[l].
  7. Java: >>> for logical shift; never 1 << 32 on an int.

Java implementation

Count the unique element with a map. XOR drops the extra memory.

JavaBitBrute.java
import java.util.HashMap;
    import java.util.Map;
    
    public class BitBrute {
        static int singleNumber(int[] a) {
            Map<Integer, Integer> c = new HashMap<>();
            for (int v : a) {
                c.merge(v, 1, Integer::sum);
            }
            for (var e : c.entrySet()) {
                if (e.getValue() == 1) {
                    return e.getKey();
                }
            }
            return 0;
        }
    
        public static void main(String[] args) {
            System.out.println(singleNumber(new int[] {4, 1, 2, 1, 2}));
        }
        // Input : [4, 1, 2, 1, 2]
        // Output: 4
    }

XOR fold, power-of-two, Kernighan popcount, and prefix XOR.

JavaBitOps.java
import java.util.Arrays;
    
    public class BitOps {
        static int singleNumber(int[] a) {
            int x = 0;
            for (int v : a) {
                x ^= v;
            }
            return x;
        }
    
        static boolean isPowerOfTwo(int x) {
            return x > 0 && (x & (x - 1)) == 0;
        }
    
        static int popcount(int x) {
            int c = 0;
            while (x != 0) {
                x &= x - 1;
                c++;
            }
            return c;
        }
    
        static int[] prefixXor(int[] a) {
            int n = a.length;
            int[] p = new int[n + 1];
            for (int i = 0; i < n; i++) {
                p[i + 1] = p[i] ^ a[i];
            }
            return p;
        }
    
        public static void main(String[] args) {
            System.out.println(singleNumber(new int[] {4, 1, 2, 1, 2}));
            System.out.println(isPowerOfTwo(8) + " " + isPowerOfTwo(7));
            System.out.println(popcount(12));
            System.out.println(Arrays.toString(prefixXor(new int[] {1, 2, 3})));
        }
        // Input : [4,1,2,1,2]; 8 and 7; popcount 12; prefix XOR [1,2,3]
        // Output: 4
        //         true false
        //         2
        //         [0, 1, 3, 0]
    }

Enumerate subsets as masks. Sum of each subset stored in a long.

JavaBitmaskSubsets.java
import java.util.ArrayList;
    import java.util.List;
    
    public class BitmaskSubsets {
        static List<Long> subsetSums(int[] a) {
            int n = a.length;
            List<Long> out = new ArrayList<>();
            for (int mask = 0; mask < (1 << n); mask++) {
                long s = 0;
                for (int i = 0; i < n; i++) {
                    if ((mask & (1 << i)) != 0) {
                        s += a[i];
                    }
                }
                out.add(s);
            }
            return out;
        }
    
        /** Number of (mask, submask) pairs is 3^n. Includes the empty submask. */
        static long countSubmasks(int n) {
            long cnt = 0;
            for (int mask = 0; mask < (1 << n); mask++) {
                for (int sub = mask; ; sub = (sub - 1) & mask) {
                    cnt++;
                    if (sub == 0) break;
                }
            }
            return cnt;
        }
    
        public static void main(String[] args) {
            System.out.println(subsetSums(new int[] {1, 2, 4}));
            System.out.println(countSubmasks(3));
        }
        // Input : subset sums of [1, 2, 4]; submasks of n = 3
        // Output: [0, 1, 2, 3, 4, 5, 6, 7]
        //         27
    }

Complexity

Time XOR fold O(n); popcount O(set bits); subset enum O(2^n · n) Space O(1) for folds; O(2^n) if you store every subset sum

XOR / AND / OR of n integers is one pass: Θ(n). Kernighan popcount is Θ(popcount(x)).

Subset enumeration: 2^n masks, n bit tests each, T(n) = Θ(n 2^n). Submask enumeration of one mask with popcount p is 2^p. n=20 is about 20 million operations; n=25 is already tight in Java.

Edge cases and pitfalls

  • 1 << 31 and 1 << 32 on int
    1 << 31 is Integer.MIN_VALUE (negative). 1 << 32 is 1 because the shift count is masked to 5 bits.
    1L << k for k up to 62. Never shift an int by ≥ 32.
  • Arithmetic >> on a sign bit
    -1 >> 1 stays -1 (sign extend). Logical fill needs >>>.
    Unsigned / bit patterns: >>>. Java has no unsigned int type.
  • x & (x-1) on x=0
    Power-of-two test without x > 0 accepts 0, and negatives.
    x > 0 && (x & (x-1)) == 0.
  • XOR of a subarray without a prefix
    Recomputing XOR(l..r) in O(r-l) per query dies at n,q=1e5.
    Prefix XOR array, query is p[r+1] ^ p[l].
  • Mask loop with n=31 on int
    1 << n overflows the loop bound; signed int 2^31 is negative.
    n≤30 for int masks; use 1L << n and a long loop.

Interview follow-ups

Two unique numbers, everything else twice?

XOR everything to get a^b. The lowest set bit of a^b is a bit they differ on. Partition the array by that bit and XOR-fold each part: LC 260.

Why is n & -n the lowest set bit?

Two's complement: -n is ~n+1. Adding one flips trailing ones into zeros and the first zero into a one, which is exactly the lowest set bit of n, and AND isolates it.

Enumerate only submasks of m, not all 2^n?

for (int s = m; s != 0; s = (s-1) & m) then handle s=0. That is SOS / subset-convolution's inner loop. 3^n over all (mask, submask) pairs.

Maximum XOR pair in O(n)?

Not with masks. Build a binary trie of the numbers (or of prefix XORs for subarrays) and greedy-match the opposite bit. See XOR trie.

Recap

  • XOR cancels pairs; prefix XOR is the subarray identity.
  • x & (x-1) drops the lowest set bit; x & -x isolates it.
  • A mask is a subset; n ≤ 20 enumerates 2^n.
  • Use 1L << k and >>> for bit patterns.
  • Integer.bitCount exists; do not roll it unless teaching.
