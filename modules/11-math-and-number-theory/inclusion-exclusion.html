Inclusion-Exclusion

|A∪B|=|A|+|B|-|A∩B|. For n sets the sign is (-1)^{|S|+1}. The same sum counts surjections, derangements, and coprime lattice points.

Hard 22 min read Prerequisites: Combinatorics, Primes & Sieves inclusion-exclusion PIE Möbius P2

Why this exists

"How many integers ≤ n are divisible by 2 or 3 or 5?" is add singles, subtract pairs, add the triple. The same loop counts derangements and gcd==1 pairs.

In code: loop 2^k subsets of k properties, sign = popcount parity. 2^k times the cost of one intersection must fit.

Möbius inversion packages IE on the divisor lattice: Σ_{d|n} μ(d)=[n==1]. Coprime pairs become Σ μ(d) floor(n/d)^2.

You can count a union if you can count every intersection. An element in exactly r sets is counted C(r,1)-C(r,2)+...=1 time.

Recognise this pattern

Say yes when you see

  • Union of k≤20 sets, each intersection easy
  • Count ≤ n coprime to m
  • Derangements n! Σ (-1)^k/k!
  • Surjections onto k labels
  • Stars-and-bars with upper bounds

Not this pattern when

  • k=40 unstructured properties → 2^40 dies
  • Subset DP is cheaper
  • You cannot count A∩B
  • Just one set

Core idea and the invariant

For mask≠0, count the intersection of those properties. Sign + for odd popcount (union). Sum.

Möbius: sieve μ; g(n)=Σ_{d|n} μ(d) f(n/d). gcd==1 is the textbook application.

Σ_j C(r,j)(-1)^{j+1} = 1 for r≥1, so every element in the union is counted once.

Java implementation

JavaUnionBrute.java
public class UnionBrute {
        static int count(int n, int[] p) {
            int c = 0;
            outer:
            for (int x = 1; x <= n; x++)
                for (int v : p) if (x % v == 0) { c++; continue outer; }
            return c;
        }
        public static void main(String[] args) {
            System.out.println(count(10, new int[] {2, 3}));
        }
        // Input : 1..10, div by 2 or 3
        // Output: 7
    }
JavaInclusionExclusion.java
public class InclusionExclusion {
        static long unionDiv(long n, int[] p) {
            int k = p.length;
            long ans = 0;
            for (int m = 1; m < (1 << k); m++) {
                long prod = 1;
                int bits = 0;
                boolean ov = false;
                for (int i = 0; i < k; i++) if (((m >> i) & 1) == 1) {
                    bits++;
                    if (prod > n / p[i]) { ov = true; break; }
                    prod *= p[i];
                }
                if (ov) continue;
                long term = n / prod;
                ans += (bits % 2 == 1) ? term : -term;
            }
            return ans;
        }
        public static void main(String[] args) {
            System.out.println(unionDiv(10, new int[] {2, 3}));
            System.out.println(unionDiv(10, new int[] {2, 3, 5}));
        }
        // Input : 10 with {2,3} and {2,3,5}
        // Output: 7
        //         8
    }
JavaMobiusGcd.java
import java.util.*;
    public class MobiusGcd {
        static int[] mu;
        static void sieve(int n) {
            mu = new int[n + 1];
            int[] spf = new int[n + 1];
            mu[1] = 1;
            List<Integer> pr = new ArrayList<>();
            for (int i = 2; i <= n; i++) {
                if (spf[i] == 0) { spf[i] = i; pr.add(i); mu[i] = -1; }
                for (int p : pr) {
                    long v = (long) i * p;
                    if (v > n) break;
                    spf[(int) v] = p;
                    mu[(int) v] = (i % p == 0) ? 0 : -mu[i];
                    if (i % p == 0) break;
                }
            }
        }
        static long coprimePairs(int n) {
            sieve(n);
            long ans = 0;
            for (int d = 1; d <= n; d++) ans += (long) mu[d] * (n / d) * (n / d);
            return ans;
        }
        public static void main(String[] args) {
            System.out.println(coprimePairs(3));
        }
        // Input : pairs in 1..3 with gcd 1
        // Output: 7
    }

Edge cases and pitfalls

  • Wrong sign / empty mask
    Mask 0 adds the universe.
    Skip 0; + on odd popcount.
  • Product overflow
    lcm wraps; n/prod is junk.
    If prod would exceed n, skip.
  • μ of a square not zeroed
    mu[i*p]=-mu[i] even when p|i.
    If p|i, μ=0.
  • Derangement integer /
    n!/k! must stay exact.
    Running mul or mods.
  • min(|A|,|B|) as intersection
    Not the size of A∩B.
    Count from the structure (lcm, both constraints).

Interview follow-ups

Why is an r-set element counted once?

Σ C(r,j)(-1)^{j+1}=1 for r≥1.

Möbius vs raw IE?

Möbius is IE on the divisor poset with μ precomputed.

n=1e12 in Σ μ(d) floor(n/d)^2?

Cannot sieve to 1e12. Need Du-Jiao / min_25, or n≤1e7.

Three-set formula?
