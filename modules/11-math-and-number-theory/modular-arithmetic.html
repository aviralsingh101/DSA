Modular Arithmetic

Work in the ring Z/MZ: add and multiply with % M, invert when gcd(a,M)=1, and never write (a-b)%M in Java without fixing a negative remainder.

Easy 22 min read Prerequisites: Complexity Analysis, Java for DSA mod inverse P0

Why this exists

Contest answers are almost always needed modulo 1e9+7 or 998244353. Those are primes, so every non-zero residue has an inverse and you may divide. Composite moduli lose inverses and need CRT / phi.

Java's % on negatives is negative. Hashing, prefix differences, and a-b all hit this. The one-liner x%=M; if(x<0)x+=M; belongs in muscle memory.

Fermat: a^{M-2} ≡ a^{-1} (mod M) for prime M. Binary exponentiation is O(log M). The next pages add sieves, phi, and CRT.

(a+b) mod M = (a mod M + b mod M) mod M. Subtraction needs a +M. Division is multiply by the inverse, not Java /.

Recognise this pattern

Say yes when you see

  • Output modulo a prime (1e9+7, 998244353)
  • Need a/b mod P, i.e. a * b^{P-2}
  • Prevent overflow of n! or a^b
  • Binomial coefficients mod a prime
  • Prefix hashes and differences in a modular ring

Not this pattern when

  • Modulo a composite when you need inverses of all residues → not a field
  • Actual integer division of the answer, not modular → do not invert
  • n=1e18 exponents with a composite mod → Euler/phi or CRT, not raw Fermat
  • Floating geometry → different page

Core idea and the invariant

Normalise: x %= M; if (x < 0) x += M;. Multiply: (a%M)*(b%M)%M in long. Pow: binary exponentiation. Inverse: pow(a, M-2) if M prime and a%M!=0.

998244353-1 = 2^23 * 119, so NTT exists. 1e9+7-1 is not a high power of two. Both are fine for inverses.

All arithmetic is in the residue classes mod M. An inverse of a exists iff gcd(a,M)=1. For prime M that is every a not ≡ 0.

Normalise, then multiply, then invert

Algorithm

  1. Store everything in long when M ~ 1e9.
  2. add: (a+b)%M with a,b already in 0..M-1 (sum fits long).
  3. sub: (a-b+M)%M.
  4. mul: (a*b)%M in long.
  5. pow(a,e): binary, O(log e).
  6. inv(a): pow(a, M-2) if M prime; else extended Euclid.

Safe add/sub/mul/pow/inv for a prime M.

JavaModulo.java
public class Modulo {
        static final long M = 1_000_000_007L;
        static long add(long a, long b) { a += b; if (a >= M) a -= M; return a; }
        static long sub(long a, long b) { a -= b; if (a < 0) a += M; return a; }
        static long mul(long a, long b) { return (a * b) % M; }
        static long pow(long a, long e) {
            long r = 1;
            while (e > 0) {
                if ((e & 1) == 1) r = mul(r, a);
                a = mul(a, a);
                e >>= 1;
            }
            return r;
        }
        static long inv(long a) { return pow(a, M - 2); }
        public static void main(String[] args) {
            System.out.println(sub(1, 4));
            System.out.println(mul(4, inv(3)));
        }
        // Input : 1-4 and 4/3 mod 1e9+7
        // Output: 1000000004
        //         333333338
    }

Generic a^e % m, m not necessarily prime.

JavaBinpow.java
public class Binpow {
        static long pow(long a, long e, long m) {
            a %= m;
            long r = 1 % m;
            while (e > 0) {
                if ((e & 1) == 1) r = (r * a) % m;
                a = (a * a) % m;
                e >>= 1;
            }
            return r;
        }
        public static void main(String[] args) {
            System.out.println(pow(2, 7, 5));
        }
        // Input : 2^7 mod 5
        // Output: 3
    }

Complexity

Time O(1) add/mul, O(log e) pow Space O(1)

Binary exponentiation does ⌊ log e ⌋ squarings. Inverse is one pow. Factorials need O(n) preprocess for n < M.

Edge cases and pitfalls

  • Negative remainder
    Hash or index becomes -3, AIOOB or missed equality.
    Always +M after sub.
  • int multiply
    1e9*1e9 overflows int before %.
    Cast to long first: (long)a * b % M.
  • inv(0)
    pow(0, M-2)=0, and you silently "divide by zero".
    Guard a%M==0.
  • Fermat on composite M
    a^{M-2} is not inv(a). Euler needs a^{phi(M)-1} and gcd=1.
    Extended Euclid, or factor M.
  • pow(a, n) with n=1e18 written as a loop
    TLE. Or using double Math.pow and rounding.
    Binary exp in the integer ring.

Interview follow-ups

Why 1e9+7?

Prime, fits in 32-bit, product of two residues fits in 64-bit, traditional. 998244353 is preferred when you might NTT.

Does (a/b)%M == (a%M)/(b%M)?

No. Integer division is not modular division. 8/2=4, but 8 * inv(2) mod 5 = 4*3=12≡2, and 8/2 as ints is 4≡4, already different stories. Always multiply by inv.

Overflow of a+b before %?

If a,b < M < 2^62, a+b fits in long. If M is 2^63-ish, subtract M instead of %.

Wilson's theorem?

(P-1)! ≡ -1 mod P. Cute check, not a primality test you should ship (too slow, and MR is better).
