Matrix Exponentiation

A linear recurrence xn = Σ ai xn-i is one matrix multiply. Binary exponentiation of that matrix jumps n steps in O(k³ log n).

Hard 28 min read Prerequisites: Modular Arithmetic, Recurrences matrix expo linear recurrence P2

Why this exists

You are asked for the n-th Fibonacci number, or the number of ways to tile a 2 × n board, and n can be 1018. Adding the last two terms in a loop is 1018 additions and will not return. The same blow-up hits “walks of length n” on a small graph: raising the adjacency matrix by multiplying it n times is still linear in n. You need a way to jump many steps at once.

If the next state is always a fixed linear mix of the current state — written St+1 = A St, where A is a k × k matrix of coefficients and St is a column of k numbers — then the state after n steps is leftover of An S0. That power is the same binary exponentiation you already know for scalars, except each multiply is a matrix multiply. Fibonacci is the 2-by-2 case; a k-term recurrence is a k-by-k companion matrix; walks are the adjacency matrix.

The constraint that names this page is n ≤ 1018 next to a linear recurrence or a small graph. The state size k is 2 for Fibonacci, 3 to 6 for many tilings, and |V| for walks. Each matrix multiply is about k3 cell products, and you do about 60 of them, so k = 20 is comfortable and k = 100 is already a million times sixty modular multiplies, borderline in Java.

If the recurrence is not linear — xn = xn-12, or a min / max that is not a linear combination — a matrix cannot encode the step and this page does not apply. If n is only a million and k is huge, just iterate the recurrence. Shortest paths use a different semiring and are not this multiply.

Once you write the state as a column of the last k terms, there is only one matrix A that sends that column to the next column. After that the whole problem is binary exponentiation of A, which computes leftover of An and therefore the state after n steps.

Recognise this pattern

Say yes when you see

  • n-th Fibonacci / Tribonacci / linear recurrence, n ≤ 10^18
  • Ways to tile / hop with a fixed profile after n steps
  • Number of walks of length n in a small graph (A^n[u][v])
  • Sum of a linear recurrence, or "first n Fibonaccis" via a larger matrix
  • DP transition is a fixed linear map, you need the n-th iterate

Not this pattern when

  • Non-linear recurrences (x_n = x_{n-1}^2) — matrix expo does not apply
  • n ≤ 1e6 and k huge — just iterate the recurrence
  • Shortest path — min-plus "multiplication" is a different semiring (and usually not what they want)
  • Arbitrary DP with max / min that is not a linear combination

Core idea and the invariant

Fibonacci first, so the letters mean something. Let the state column be the pair (Ft, Ft-1). The next pair is (Ft+1, Ft) = (Ft+Ft-1, Ft), which is what the matrix A = [[1, 1], [1, 0]] computes when it multiplies the current column: first row is “sum the two entries”, second row is “copy the first entry down”. Starting from (F1, F0) = (1, 0), leftover of An-1 times that column is (Fn, Fn-1). The top-left cell of that power is therefore leftover of Fn.

A general k-term recurrence uses a companion matrix: first row is the coefficients, and each later row is a shift that copies one old term down, which is what “remember the last k-1 terms” means. Multiply two k × k matrices in the triple loop of k3 cell products, reducing leftover the prime every time. Binary exponentiation is then the scalar loop you already know: start from the identity, square A, and multiply into the result when the current bit of n is on. Use long for every product.

Walk F10. Ten in binary is 1010, so you need leftover of A8 A2. Squaring gives A2 (which holds F2, F1), then A4 (F4, F3), then A8 (F8, F7). Multiplying the 8-step and 2-step powers produces leftover of F10 = 55. Which cell you read depends on whether you powered n or n-1 and on the base column; pick one convention and test F0=0, F1=1, F10=55. For walks, A is the adjacency matrix and leftover of An[u][v] is the number of walks from u to v of length n.

If every single step satisfies St+1 = A St, then leftover of An St is the state n steps later. Binary exponentiation computes that power by leftover of (Am)2 = A2m and leftover of A · A2m = A2m+1.

In plain words, one matrix multiply is one step of the recurrence, so a power of that matrix is many steps at once, and you build the power by squaring just as you do for a scalar.

Interview sentence: “Write the linear step as a matrix, then fast-pow the matrix.”

Off-by-one on F_0 and F_1

Powering An-1 with n = 0 underflows. Special-case zero, and test F0 = 0, F1 = 1, F10 = 55 before you trust a huge n.

Reduce every cell product

Leaving the reduce until the end of mul lets intermediate cells grow past M and then past a long. Reduce leftover the prime on every a[i][k] * b[k][j].

Structure

Algorithm

  1. Write the state column. Size k is the last k terms of the recurrence, or one slot per vertex if you are counting walks. That column is what one matrix multiply will advance.
  2. Write the matrix A that takes one step. Check by hand that leftover of A times the current column is the next column. A wrong first row is the usual silent off-by-one.
  3. Fast-pow from the identity. Start res = I and run the binary loop: square A, multiply into res on a 1-bit. Each multiply is the k3 triple loop.
  4. Reduce leftover the prime on every cell. Use long for the product. Skipping the reduce lets a cell grow past a long and the leftover is garbage.
  5. Multiply the power by S_0 and read the answer cell. That cell is leftover of the term the statement asked for. Do not print a random entry of An.
  6. Test n = 0, 1, and 10. Fibonacci powered as An-1 underflows at zero. Confirm F0 = 0, F1 = 1, F10 = 55 before a huge exponent.

Java implementation

JavaFibLoop.java
public class FibLoop {
        static long fib(int n) {
            if (n <= 1) return n;
            long a = 0, b = 1;
            for (int i = 2; i <= n; i++) { long c = a + b; a = b; b = c; }
            return b;
        }
        public static void main(String[] args) {
            System.out.println(fib(10));
        }
        // Input : n=10
        // Output: 55
    }

2×2 matrix expo, O(log n).

JavaFibMat.java
public class FibMat {
        static final long MOD = 1_000_000_007L;
        static long[][] mul(long[][] a, long[][] b) {
            long[][] c = new long[2][2];
            for (int i = 0; i < 2; i++)
                for (int k = 0; k < 2; k++)
                    for (int j = 0; j < 2; j++)
                        c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % MOD;
            return c;
        }
        static long[][] pow(long[][] a, long n) {
            long[][] r = {{1, 0}, {0, 1}};
            while (n > 0) {
                if ((n & 1) == 1) r = mul(r, a);
                a = mul(a, a);
                n >>= 1;
            }
            return r;
        }
        static long fib(long n) {
            if (n == 0) return 0;
            return pow(new long[][] {{1, 1}, {1, 0}}, n - 1)[0][0];
        }
        public static void main(String[] args) {
            System.out.println(fib(10));
        }
        // Input : n=10
        // Output: 55
    }

k×k multiply + pow. Plug any companion / adjacency matrix.

JavaMatPow.java
public class MatPow {
        static long[][] mul(long[][] a, long[][] b, long MOD) {
            int n = a.length;
            long[][] c = new long[n][n];
            for (int i = 0; i < n; i++)
                for (int k = 0; k < n; k++) if (a[i][k] != 0)
                    for (int j = 0; j < n; j++)
                        c[i][j] = (c[i][j] + a[i][k] * b[k][j]) % MOD;
            return c;
        }
        static long[][] pow(long[][] a, long e, long MOD) {
            int n = a.length;
            long[][] r = new long[n][n];
            for (int i = 0; i < n; i++) r[i][i] = 1;
            while (e > 0) {
                if ((e & 1) == 1) r = mul(r, a, MOD);
                a = mul(a, a, MOD);
                e >>= 1;
            }
            return r;
        }
        public static void main(String[] args) {
            long[][] A = {{1, 1}, {1, 0}};
            System.out.println(pow(A, 9, 1_000_000_007L)[0][0]);
        }
        // Input : Fib companion ^ 9 → F_10
        // Output: 55
    }

Complexity

Time O(k³ log n) Space O(k²)

Binary exponentiation does about log2 n squarings and a handful of extra multiplies on 1-bits. Each multiply of two k × k matrices is k3 cell products, so the whole power is about k3 log n modular multiplies. A sparse adjacency (a path, a cycle) can drop a factor if you skip zero cells, but you should not count on that in the worst case.

Putting real numbers in: Fibonacci is k = 2, so about 8 × 60 = 480 cell products at n = 1018, a few microseconds. A tiling profile with k = 20 is 8000 × 60 = 4.8 × 105 multiplies, comfortable. At k = 100 you are near 6 × 107 multiplies, tight in Java. Looping the recurrence at n = 1018 is impossible; looping it at n = 106 is faster than building matrices.

Edge cases and pitfalls

  • n = 0 or n = 1
    Powering An-1 with n = 0 underflows a long, or you return leftover of A[0][0] as F0, which is 1 rather than 0. Small samples that start at n = 10 hide it.
    Special-case zero. Test leftover of F0 = 0, F1 = 1, and F10 = 55 before a huge exponent.
  • int overflow before mod
    A cell product of two residues near 109, accumulated k times without a reduce, can exceed 263 and wrap a long. The leftover then looks like a plausible Fibonacci number.
    Reduce both factors leftover the prime first; then one product fits in a long. Reduce again after adding into the cell.
  • Result matrix vs base vector
    You print leftover of An[0][0] but the identity you proved was leftover of An-1 times the start column, so every answer is the wrong Fibonacci.
    Write one step on paper and match the pair (Fn, Fn-1). The three-value test above catches the shift.
  • Forgetting the modulus on the identity
    The identity is already reduced, so it looks safe, but intermediate cells of later multiplies grow past the prime and then past a long if you only reduce at the end of mul.
    Reduce leftover the prime on every cell product inside mul, not once after the triple loop.
  • Min-plus for shortest paths of length n
    Ordinary plus-and-times counts walks and produces a large number that looks like a distance on tiny graphs. The statement asked for a shortest path of length n.
    Walks use leftover of plus and times. A shortest k-edge path uses min and plus, a different semiring, and is rarely what a matrix-expo problem wants.

Interview follow-ups

Why companion matrix looks like that?

The first row is the linear combination that computes the newest term from the previous k terms — those are the recurrence coefficients. Every later row is a shift: it copies one old term one slot down so the next column still holds a window of the last k values. That is what “remember the last k-1 terms” means, written as a matrix so you can raise it to a power.

Can you do better than k³?

Strassen's multiply helps only for huge k that contests do not use. For a single linear recurrence, Berlekamp–Massey plus Kitamasa computes the n-th term in about k2 log n, which is worth it around k ~ 1000 and overkill at k = 20. Quote k3 log n unless someone asks.

How do you get the sum of a geometric of matrices?

The sum leftover of I + A + ... + An-1 is the total of the first n states if each state is a matrix power. If n is even it factors as leftover of (I + A^{n/2}) times the half-sum, which is a doubling just like the power. The other route is to augment the state with a running total so one extra row accumulates the newest term.

Interview: Fib O(log n) without matrices?

The doubling identities leftover of F(2n) = F(n)(F(n+1)+F(n-1)) and leftover of F(2n+1) = F(n)2 + F(n+1)2 give the same log n without storing arrays. They are Fibonacci-only. Matrices are the form that still works for a 5-state tiling or a graph walk, which is why interviews accept either and prefer the matrix once the recurrence is not Fibonacci.
