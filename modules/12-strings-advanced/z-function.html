Z-Function

Z[i] is the longest substring starting at i that matches the prefix of s. One linear pass maintains a rightmost Z-box.

Medium 22 min read Prerequisites: KMP & the Prefix Function, Two Pointers Z-function string P1

Why this exists

Many string problems ask "how much of a prefix starts here?": pattern matching (Z of p+'#'+t), distinct substrings via suffixes, and string-period recovery. The Z-array answers every such question after one O(n) pass.

The algorithm keeps a window [l, r] that is a prefix-match already computed (a Z-box). For a new i inside that box, Z[i] is at least min(Z[i-l], r-i+1), and you only extend when the known copy runs out. That is the same two-pointer idea as Manacher.

Z and the prefix function determine each other. Prefer Z when the question is phrased as prefix matches at every index; prefer π when you are building failure links.

Inside a Z-box you already know a prefix copy. Reuse Z[i-l] instead of matching from scratch, and only extend when that copy is shorter than the remaining box.

Recognise this pattern

Say yes when you see

  • Longest prefix starting at every index
  • Pattern matching via Z of p+'#'+t: hits where Z[i]==|p|
  • Number of distinct substrings in O(n^2) made practical as sum n-Z over suffixes, or with SA
  • You already think in [l,r] windows (Manacher cousin)
  • String compression / period from Z[i]==n-i

Not this pattern when

  • Failure-link automaton → prefix function
  • Palindromes → Manacher
  • Many patterns → Aho-Corasick
  • Substring lexicographic order → suffix array

Core idea and the invariant

Z[0] is 0 or n by convention (we store 0 and never use it). Maintain [l, r] = rightmost segment that matches a prefix. For i=1..n-1: if i≤r, Z[i] = min(r-i+1, Z[i-l]). Then while i+Z[i]<n and s[Z[i]]==s[i+Z[i]], increment. If i+Z[i]-1 > r, reset [l,r] to [i, i+Z[i]-1].

Matching: Z-array of p+'#'+t. Every position in the t-half with Z[i]==|p| is a hit starting at i-(|p|+1).

[l, r] is a prefix of s, copied at l. For every i in (l, r], the prefix of length Z[i-l] starting at i is already known to match, up to the box edge r.

Rightmost Z-box

Algorithm

  1. Z[0]=0 (or n, but then never treat it as a match start).
  2. l=r=0. For i=1..n-1:
  3. If i≤r set Z[i]=min(r-i+1, Z[i-l]).
  4. Extend while in bounds and characters match.
  5. If i+Z[i]-1 > r set l=i, r=i+Z[i]-1.
  6. Match on p+'#'+t as with KMP.

Java implementation

Match a prefix from every i. Quadratic.

JavaZBrute.java
import java.util.Arrays;
    public class ZBrute {
        static int[] z(String s) {
            int n = s.length();
            int[] z = new int[n];
            for (int i = 1; i < n; i++) {
                while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) z[i]++;
            }
            return z;
        }
        public static void main(String[] args) {
            System.out.println(Arrays.toString(z("ababac")));
        }
        // Input : ababac
        // Output: [0, 0, 3, 0, 1, 0]
    }

Linear Z-array via the rightmost box.

JavaZFunction.java
import java.util.Arrays;
    public class ZFunction {
        static int[] z(String s) {
            int n = s.length();
            int[] z = new int[n];
            for (int i = 1, l = 0, r = 0; i < n; i++) {
                if (i <= r) z[i] = Math.min(r - i + 1, z[i - l]);
                while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) z[i]++;
                if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; }
            }
            return z;
        }
        public static void main(String[] args) {
            System.out.println(Arrays.toString(z("ababac")));
        }
        // Input : ababac
        // Output: [0, 0, 3, 0, 1, 0]
    }

Occurrences of p in t.

JavaZMatch.java
import java.util.*;
    public class ZMatch {
        static int[] z(String s) {
            int n = s.length();
            int[] z = new int[n];
            for (int i = 1, l = 0, r = 0; i < n; i++) {
                if (i <= r) z[i] = Math.min(r - i + 1, z[i - l]);
                while (i + z[i] < n && s.charAt(z[i]) == s.charAt(i + z[i])) z[i]++;
                if (i + z[i] - 1 > r) { l = i; r = i + z[i] - 1; }
            }
            return z;
        }
        static List<Integer> find(String t, String p) {
            int[] z = z(p + "#" + t);
            List<Integer> ans = new ArrayList<>();
            int m = p.length();
            for (int i = 0; i < t.length(); i++) if (z[m + 1 + i] == m) ans.add(i);
            return ans;
        }
        public static void main(String[] args) {
            System.out.println(find("ababa", "aba"));
        }
        // Input : ababa / aba
        // Output: [0, 2]
    }

Complexity

Time O(n) Space O(n)

Each extend comparison that succeeds increases r. r never decreases. Failed comparisons happen at most once per i after the copied value. Total O(n).

Edge cases and pitfalls

  • Using Z[0]=n in the copy
    i-l = 0 copies n and you run off the array.
    Leave Z[0]=0, or special-case i=l.
  • Updating [l,r] with a weaker box
    Setting r to a smaller value loses the amortised bound and can even make Z too small if you skip extend.
    Only widen when i+Z[i]-1 > r.
  • min(r-i+1, Z[i-l]) without extend
    When Z[i-l] hits the box edge, the match might continue past r.
    Always run the while after the copy.
  • Sentinel missing
    Same as KMP: Z of p+t without '#' can cross the join.
    A character outside the alphabet.
  • Comparing chars with == on substrings
    In Java, s.substring(a)==s.substring(b) is reference equality.
    charAt in the extend loop, as written.

Interview follow-ups

Why copy min(r-i+1, Z[i-l])?

The box says s[l..r]==s[0..r-l]. Position i corresponds to i-l in the prefix. You cannot claim more than the remaining box, and you cannot claim more than Z[i-l].

Z vs KMP for matching?

Same complexity. Z is slightly more code for matching and slightly less conceptual load if the problem is already "prefix at i". KMP automata compose better with Aho.

Can Z handle wildcards?

Not by itself. Split the pattern on '?', Z-match each chunk, and check gaps. Or use FFT string matching.

Manacher uses the same idea?

Yes: a palindrome box [l,r] and copy the mirrored radius, then extend. Once you can write Z, Manacher is a palindrome-flavoured Z.

Recap

  • Z[i] = longest prefix starting at i.
  • Reuse the rightmost Z-box; only extend when needed.
  • r only moves right → O(n).
  • Match with p+'#'+t, Z[i]==|p|.
  • Cousin of Manacher's mirrored window.
