KMP & the Prefix Function

The prefix function π[i] is the longest proper prefix of s[0..i] that is also a suffix — KMP matching is one scan using those borders.

Medium 24 min read Prerequisites: Two Pointers, Hashing Patterns KMP prefix function string P1

Why this exists

Naive string matching retries after every mismatch and is O(nm). Knuth-Morris-Pratt never rewinds the text pointer: a mismatch jumps the pattern to its next possible border, computed once as the prefix function.

π[i] is the longest proper prefix of s[0..i] that is also a suffix of s[0..i]. Those borders nest, so a mismatch at i walks π like a failure link. The same array finds periods (i+1 is divisible by i+1-π[i]), counts occurrences, and builds the KMP automaton.

Contest problems hide this as "shortest period", "string that is a prefix of every cyclic shift", and "count pattern hits allowing overlap". Rolling hash is the randomised alternative; KMP is deterministic linear time.

A mismatch at i means the candidate border of length q failed. The next candidate is π[q-1], the longest border of that border. You never skip a possible alignment.

Recognise this pattern

Say yes when you see

  • Find all occurrences of pattern p in text t, overlaps allowed, in O(|t|+|p|)
  • Shortest period of a string: n % (n - π[n-1]) == 0
  • Build a failure automaton and feed many texts
  • "String matching without hashing / without false positives"
  • Compress a string by its border structure

Not this pattern when

  • Many different patterns in one text → Aho-Corasick
  • You only need palindromes → Manacher
  • You need lexicographic suffix order → suffix array
  • One equality test of two whole strings → just compare, or a hash

Constraint tell: |s| ≤ 10⁶ is the linear-string window. Build is strictly O(n). Recursion is not involved.

Core idea and the invariant

Compute π in one pass. Keep the current border length q. For each i, while q>0 and s[i]!=s[q], q=π[q-1]. Then if s[i]==s[q] q++. π[i]=q.

To match p in t, compute π of p + '#' + t (the sentinel must not appear in either). Every index in the t-region with π[i]==|p| is an occurrence ending at that index.

π[i] = max { k : k < i+1, s[0..k) = s[i-k+1..i] }, or 0. After processing i, q is that value, and it is the only border length you need to try next.

Algorithm

  1. Allocate int[] pi = new int[n]. q starts at 0.
  2. For i = 1..n-1 (pi[0] is always 0).
  3. While q>0 and s[i]!=s[q], q = pi[q-1].
  4. If s[i]==s[q], q++.
  5. pi[i] = q.
  6. Match: build pi of p+'#'+t; report every i with pi[i]==p.length().

        static List<Integer> find(String t, String p) {
            List<Integer> ans = new ArrayList<>();
            for (int i = 0; i + p.length() <= t.length(); i++) {
                if (t.regionMatches(i, p, 0, p.length())) ans.add(i);
            }
            return ans;
        }

        }

        // Output: [0, 2]
    }

Prefix function, then match via the sentinel concatenation.

JavaKmp.java
import java.util.*;
    public class Kmp {
        static int[] prefix(String s) {
            int n = s.length();
            int[] pi = new int[n];
            for (int i = 1, q = 0; i < n; i++) {
                while (q > 0 && s.charAt(i) != s.charAt(q)) q = pi[q - 1];
                if (s.charAt(i) == s.charAt(q)) q++;
                pi[i] = q;
            }
            return pi;
        }
        static List<Integer> find(String t, String p) {
            int[] pi = prefix(p + "#" + t);
            List<Integer> ans = new ArrayList<>();
            int m = p.length();
            for (int i = 0; i < t.length(); i++) {
                if (pi[m + 1 + i] == m) ans.add(i - m + 1);
            }
            return ans;
        }
        public static void main(String[] args) {
            System.out.println(find("ababa", "aba"));
            System.out.println(Arrays.toString(prefix("ababac")));
        }
        // Input : ababa / aba, and pi of ababac
        // Output: [0, 2]
        //         [0, 0, 1, 2, 3, 0]
    }

Shortest period from the last prefix value.

JavaPeriod.java
public class Period {
        static int period(String s) {
            int n = s.length();
            int[] pi = new int[n];
            for (int i = 1, q = 0; i < n; i++) {
                while (q > 0 && s.charAt(i) != s.charAt(q)) q = pi[q - 1];
                if (s.charAt(i) == s.charAt(q)) q++;
                pi[i] = q;
            }
            int p = n - pi[n - 1];
            return n % p == 0 ? p : n;
        }
        public static void main(String[] args) {
            System.out.println(period("ababab"));
            System.out.println(period("abcab"));
        }
        // Input : ababab, then abcab
        // Output: 2
        //         5
    }

Complexity

Time O(n) Space O(n)

q increases by at most 1 per i, and every while-iteration decreases q by at least 1. So the inner loop runs ≤ n times total. Matching is one prefix-function call on |p|+|t|+1 characters.

ApproachTimeSpaceWhen it is enough
Naive alignO(n m)O(1)tiny strings
KMP / prefix functionO(n+m)O(n+m)One pattern, deterministic

Edge cases and pitfalls

  • Missing the sentinel
    Computing π of p+t without '#'. A border can cross the boundary and invent fake matches.
    A character that appears in neither string, or match with a separate automaton.
  • Off-by-one on occurrence index
    π[i]==|p| means the match ends at i in the concatenated string.
    Start index in t is i - |p| - |p| - 1 + 1 wait: i is in concat; t-index = i - (m+1) - m + 1 = i - 2m. Prefer looping i over t as in the code.
  • Period formula without the divisibility check
    abcab has π[n-1]=2, n-π=3, but the string is not (abc) repeating.
    Period is n-π[n-1] only when that value divides n.
  • Using π[q] instead of π[q-1]
    Infinite loop or skipped borders. The border of a string of length q lives at index q-1.
    The while is q = pi[q-1].
  • char vs Character in Java
    Building the concat with a char that exists in the input (space, '#', '$').
    Pick a char outside the alphabet, or use an int[] with a sentinel code.

Interview follow-ups

Z-function vs prefix function?

Z[i] is the longest substring starting at i that matches a prefix. π[i] is the longest border ending at i. You can convert either way in O(n). KMP matching is more natural from π.

Why is the inner loop amortised O(1)?

Think of q as a potential. Each i increases it by at most 1. Each while-step decreases it. Total decreases ≤ total increases ≤ n.

How do you match without concatenating?

Build π of p only. Scan t with the same while/if, and when q==|p| record a hit and set q=π[q-1].

Can KMP find the lexicographically smallest rotation?

Booth's algorithm: KMP on s+s, keep the smallest border-aware start. Duval / Lyndon is the other school.

Recap

  • π[i] = longest proper border of s[0..i].
  • On mismatch, q = π[q-1], never i-- on the text.
  • Match via p+'#'+t, or an automaton on p.
  • Period p = n-π[n-1] when p divides n.
  • Inner while is amortised O(1) by a potential on q.
