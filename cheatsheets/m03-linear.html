Mono stack NGE

for i=0..n:
  while(!st.empty() && a[st.peek()]<a[i])
    nge[st.pop()]=i;
  st.push(i);

Mono deque max

while(!dq.isEmpty() && a[dq.peekLast()]<=a[i]) dq.pollLast();
dq.offerLast(i);
if(dq.peekFirst()<=i-k) dq.pollFirst();

Floyd cycle

fast=fast.next.next
when meet: slow=head
advance both → entry

Heap k-largest

PriorityQueue<Integer> pq; // min-heap
for v: if(pq.size()==k && v>pq.peek()) pq.poll();
pq.offer(v);
